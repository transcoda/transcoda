The Jobs page fits narrow windows. The Today tiles and the weekly charts wrap into two columns instead of squeezing into one row. A long status such as "Would replace if it saves ≥ 25%" wraps inside its column instead of running into Result. When the table is short of room, it hides Library and Workflow so that Status, Result and When stay in view; both are still on each job's page.
