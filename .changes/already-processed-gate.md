The new Already processed step checks whether a file has already been through a workflow, this one or another, in any version or a specific one. It recognises files Transcoda wrote, even after they replaced the original. Files Transcoda writes as MKV also carry a tag naming the workflows that made them, so they are still recognised after being copied or downloaded again; MP4 files are recognised only while they are the exact file Transcoda wrote.
