Pages look and read more alike: one chip style where "Kept original" and other no-change outcomes are a quiet grey outline, one heading style, plain stat tiles, and dates like "8 min ago" or "Oct 25". The Jobs page fits the list above the fold, with the 7-day charts and the encoder's last hour side by side and the queue controls in the header; every row opens its job with one click. A run's page leads with what it saved and lists its files without the extra columns, as cards on a phone.
The job page shows the result right under the header: what changed, or why the file failed or was left alone, in plain words, with the raw command and log one click away. Empty sections are gone.
The workflow editor's top bar is calmer: Save is the one lime button, and Run on a file, Activate and Save with a note live in the ⋯ menu. The version pill says whether that version is active, and the right panel shows only the issues list until you select a node. New workflow shows the chosen kind with a lime outline and puts Create on the right.
Libraries keep the path on one line, show recycle and hardlink settings only when changed, and show each library's workflow with the same Active pill as the Workflows page. Settings show one heading and only the values you've changed, with server-set values tucked away. Sign in names the server once.
