Libraries now pick up new videos on their own: a minute after Transcoda starts and then every 15 minutes, each library with an active workflow queues the files it hasn't seen yet, so you no longer need to press Scan now. Files still being copied wait for the next check, and files Transcoda already processed are never queued again. The first check after updating also queues any file in a library that was never scanned.
